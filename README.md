# Digit Recognizer: распознавание рукописных цифр

Проект на датасете Kaggle Digit Recognizer, основанном на MNIST — классическая задача мультиклассовой классификации, где по изображению рукописной цифры 28x28 пикселей в градациях серого нужно определить, какая цифра на нём изображена (0-9). В train.csv каждая строка — это метка класса и 784 значения яркости пикселей, в test.csv — только пиксели, для которых нужно получить предсказания.

Идея проекта — сравнить между собой принципиально разные подходы к одной и той же задаче: классический ML и нейронные сети. Все пиксельные значения нормализуются делением на 255, данные делятся на train и validation со стратификацией по классам.

Первый подход — классический, без нейросетей: понижение размерности через PCA до 50 компонент, чтобы избавиться от избыточности пиксельного пространства, и SVM с RBF-ядром поверх сжатого представления. Второй подход — простой многослойный перцептрон (MLP) с двумя полносвязными скрытыми слоями, обучаемый напрямую на нормализованных пикселях без PCA. Третий — свёрточная сеть (CNN) с двумя блоками свёртка + пулинг, для которой изображения возвращаются к исходной форме 28x28x1, что позволяет сети учитывать пространственную структуру картинки, а не только отдельные пиксели. Именно CNN используется для финальных предсказаний и формирования submission-файла.

**Результат:** финальная модель получила **accuracy 0.98742 (98.742%) на соревновании Kaggle Digit Recognizer**.

**Источник датасета и соревнование:** https://www.kaggle.com/competitions/digit-recognizer

Проект состоит из одного notebook и папки data с исходными файлами соревнования; на выходе получается submission.csv с предсказанными цифрами для тестовой выборки.
